## 1. 怎么把页面渲染出来（可复跑）

本机 `chrome.exe` 起不来（SxS 配置损坏：`应用程序的并行配置不正确`），Edge 可以。三个坑：

| 坑 | 现象 | 绕法 |
|---|---|---|
| 命名管道 | `--headless=new` 直接崩：`mojo ... platform_channel.cc Check failed 拒绝访问` | 需要能创建命名管道的权限；`--single-process` **不解决问题**（同样的 mojo 断言） |
| SSE 长连接 | `--screenshot=...` 永远不返回（页面 load 之后事件流不断，截图句柄一直挂着） | 不用 `--screenshot`，改用 **CDP**：`Page.navigate` → 等 5s → `Page.captureScreenshot` |
| 写文件 | 浏览器进程写工作区里的 PNG 报 `拒绝访问 (0x5)`，写 `%TEMP%` 正常 | 截图先落 `%TEMP%`，再拷回来 |

最简复跑（三条命令）：

```powershell
# 1) 起宿主（仓库自带产物即可，不必 dotnet run —— 那会往 ~/.dotnet 写哨兵文件）
cd games/hosts/Web; .\bin\Debug\net8.0\neko-clicker-web.exe

# 2) 起无头浏览器，留一个 CDP 口
msedge --headless=new --disable-gpu --remote-debugging-port=9222 --remote-allow-origins=* ^
       --user-data-dir=%TEMP%\neko-edge about:blank

# 3) 用 CDP 驱动：取 ws 地址 → Page.navigate → 等 5s → Page.captureScreenshot
#    连 ws 时必须**不发 Origin 头**（websocket-client 的 suppress_origin=True），
#    否则浏览器回 403：Origin http://127.0.0.1:9222 不在 allow 列表里。
```

⚠️ 有一件事只有渲染才看得见：**首次进入会先弹「🌙 欢迎回来」离线收益**，遮住整页。
截图脚本要先点掉 `#offline-ok`，否则截到的是一张半透明浮层。

## 4. 方案

设计目标沿用 `app.css:1-3` 那句：「挂机时也能一眼看出它在跑」。这一版不加装饰，
只做三件事：**把尺子建起来、把层级拉开、把手机上那第一屏还回去。**

### 4.1 token（依据：`11-design-tokens.md`）

| 组 | 值 | 现在的对应 |
|---|---|---|
| 字号 | `12 / 14 / 16 / 20 / 28 / 72` | 17 个散值 |
| 间距 | `4 / 8 / 12 / 16 / 24 / 32 / 48`（×1.5 起跳） | `.15/.35/.4/.5/.55/.7/.8/.85/.9/1/1.1/1.25/1.5/2rem` |
| 圆角 | `8 / 12 / 20 / 999` | 10 种 |
| 高度 | `--e1` 卡片 · `--e2` 浮层 · `--e3` sheet | 3 条一次性 box-shadow |
| 墨色 | `--fg #ece9f7` · `--dim #b9b3d0` · `--faint #8b86a3` | 5 种灰 |
| 语义色 | `--ok / --bad / --gold / --accent` 原样 | 不变 |

`--dim` 从 `#9691b0` 提到 `#b9b3d0`（**5.34:1 → 7.98:1**）：它现在过线但只过一点点，
而 12px 的小字是全页最吃亏的一档。

### 4.2 三处结构改动（预览里已经这么画）

1. **页签 → 分段控件**：一个 1px 外框 + 里面一块选中底，代替 7 个各自带边框的按钮；
   `换包` 从行尾孤零零的 ghost 变成控件最右一格。手机上不再折成两行。
2. **建筑行 → 分隔线列表**：每行一条 `1px` 分隔线 + 16px 内边距，代替"每行一张卡 + 8px 缝"。
   现在 8 行要 **543.6px**（CSS 常量算的），改完 8 行 **470px**（`ui-plan-preview.html` 实测，
   其中两行带解锁说明），一屏多出一行；可买性仍有两个信号（价格颜色 + 整行极淡底色），
   不靠颜色单独承载（§5.7）。富余高度**落在列表之后**，不再摊进行与行之间。
3. **纪元 → hero 里的一段**：它本来就是"这一层还差多少"，不是第二个功能。降成 hero 内的一条
   进度 + 一句说明，手机首屏省下约 **120px**。

### 4.3 落地顺序（按 sweep 顺序，先结构后装饰）

| 步 | 内容 | 代价 | 为什么在这个位置 |
|---|---|---|---|
| 1 | A1 删那一行 | S | 一行改动，立刻消掉最显眼的那处"乱" |
| 2 | A3 / A5 / A6 建 type·weight·radius token | L | 后面的改动才有东西可引用 |
| 3 | A2 + 4.2 的三处结构 | M | 结构一改，A8/A10 多数自己消失 |
| 4 | A4 颜色收口（含纸主题） | M | 必须在结构定下来之后，否则重建两次 |
| 5 | A7 / A9 主按钮与高度 | S | 最后做，纯观感 |
| 6 | A8 正文宽度 | S | 顺手 |

### 4.4 验收

- 每条都配一条 `web-smoke.mjs` 结构守卫（他们那套"弄坏→抄红字→复原→sha256 一致"的做法照旧）：
  A1 断言 `.panel > .list` 里没有 `justify-content: space-between`；A3 断言 `app.css` 里
  `font-size` 的取值集合 ⊆ 6 档；A6 同理断言 `border-radius` ⊆ 4 档。
- **视觉回归**：本机现在能截图了，pptr 不必装——CDP 三段式（§1）截 1280/375 两张，
  人工对比即可；像素 diff 不做（字体渲染在不同机器上不稳）。
- 做完之后 `OPEN_WORK` H3 里"永久太散 / 右栏填满 / 两卡等高"三条可以划掉。

## 5. 没验的 / 边界

- **没测**：400~600px 高的矮窗口（sheet 的滚动与 × 够不够得着）、320px 宽、200% 缩放、
  800×360 横屏、`start.cmd` 弹不弹浏览器。
- **没测手感**：滚动、聚焦圈、金猫浮层的动效；截图是静帧。
- 数据只有一局（`apocalypse` 第 5 次重启，8 座可见建筑、5 条永久升级、9 条升级可买）。
  空状态（新包第一分钟）**没看**——那才是 §8.4 最该看的一屏，但它会覆盖真存档，这一轮没动。
- `ui-plan-preview.html` 是**方案**不是实现：不连宿主、数字是假的、没有 JS。它存在的唯一理由是
  "把 §4.1 那套 token 套到现有那一屏上会长什么样"。
