## 三、跨 agent 的教训（不属于某一个）

1. **夹具不许对线路撒谎**：`web-smoke.mjs` 的夹具写 `mode: "buy10"`（字符串），而线路送 `mode: 0`（数字）⇒ 两个套件全绿，页面却在 `render()` 中段每帧抛异常。同类的更早一次是 `lastFrameAt`（见 `FRONTEND_CHECKS.md`）。
2. **并发代价是真实的**：两个 agent 同时构建会互锁 `bin`（144 个 MSB3021/3027），而**那条失败路径泄漏过约 320 个 `dotnet` 进程、把内存吃光**——玩家侧的观感就是**数字卡死**。机器状态要连结论一起报。
3. **"我以为"必须被核对**：这个会话里我（父会话）给任务书写的判断**错了至少五次**（93 座、清单三错、那条红是"引擎过拦"、"故事框已存在"、`lore.json` 路径），**每一次都是 agent 去读代码后纠正我的**。
4. **诚实边界被反复证明有价值**：几乎每个 agent 都主动标出"我没验什么"（真浏览器、跨版本存档、合成内容、`ui` 的增量字节行为），而这些标注恰好指向后来出问题的地方。
