# Web 调试门：带密码才能跳层

> 状态：**待实现**。设计已定，代码未动。实现是 `Program.cs` 里约 30 行的改动。

---

## 1. 目标与形态

```
http://127.0.0.1:5273/?package=lab&password=<密钥>&epoch=7
```

- **`epoch=N`**：把这一局直接置到第 N 层，不用玩几小时。
- **`password=<密钥>`**：没有它，`epoch` 一律被拒。
- **默认关闭**：仓库/发布产物里不存在任何密钥，所以"没配密钥"时这个门**根本不存在**。

## 2. 密钥从哪来 —— 环境变量，不是代码常量

```
$env:NEKO_DEBUG_KEY = '随便一段短的'
start.cmd web
```

**为什么不写死在代码里**：这个仓库是公开的。写死一个常量 = 把密钥公开，等于没有门。
环境变量让默认状态成为"调试门不存在"，而想调试的人自己临时设一个。

**为什么不做成配置文件**：配置文件会被提交、会被打进 zip。环境变量不会。

## 3. 跳层的语义与它的局限（必须在响应里说出来，不能藏）

引擎没有"强行推进到第 N 层"的公开接口：`Ascend()` 要过 `EraGate`（必须完成本层主线），
而设置 `GameState.Era` 是**直接改数据**——它会**跳过**舍命该做的事：

| 跳过的东西 | 后果 | 哪些包真的受影响 |
|---|---|---|
| 跨层继承（`InheritBuildings` 比例与白名单） | 层里不会带着上一层的建筑 | **#6 末世**（唯一用非 0 继承的包），以及任何带白名单的层 |
| 层历史 `EraHistory` / `EraCompleted` | 统计与"本层耗时"不准 | 全部 |
| 结算转生货币 | 永久线相关数字不对 | 全部 |

**对"想快点看到某层的表态与结局"够用；对"验证继承/结算"不够用**——那种要用无头模拟。
所以调试门的响应里要**明确回报跳过了什么**，而不是让人以为这就是正常推进。

## 4. 一个我设计时发现的坑：别把调试状态存进存档

宿主会往 `saves/` 自动存档。跳层之后如果照常存，**玩家的真实存档就被污染了**——
而且他自己不会知道（下次进去发现层号变了）。

处理（二选一，实现时定一个并写进响应）：

- **(a) 调试模式下禁用自动存档**（推荐）：跳层只在内存里，退出即弃。
- (b) 跳到独立的调试存档槽（`saves/debug-<包名>.json`），与真实存档隔开。

推荐 (a)：它更简单，而且"调试不该留下痕迹"本来就是对的。

## 5. 拒绝行为：一律明确报错，不静默忽略

| 情况 | 响应 |
|---|---|
| 没配 `NEKO_DEBUG_KEY`，却带了 `epoch` | **403**，正文说明"调试门未启用（没设 NEKO_DEBUG_KEY）" |
| 密钥不对 | **403**，正文只说"密钥不对"（不回显正确值，也不区分"你没配"与"你配错了"之外的细节） |
| `epoch` 越界（<1 或 > 该包层数） | **400**，正文带上该包的合法范围 |
| 一切正常 | 200，正文回报：跳到了第几层、**跳过了哪些账**、以及"本次不自动存档" |

**为什么必须报错而不是忽略**：静默忽略正是这个项目一路在消灭的失败形态——
玩家会以为"我明明带了参数，怎么没生效"，然后去怀疑参数名写错、怀疑版本不对。

## 6. 安全边界（写清楚，别自我安慰）

- 宿主只监听 `127.0.0.1`，所以门只对**本机**开。
- 但 URL 会进**浏览器历史**、可能进日志。所以密钥要短、可随手换，且**不要**提交进任何文件。
- 这道门**不是**权限系统。它的目的是"别让普通玩家误触调试功能"，不是"防住有恶意的人"。
  本机使用者本来就能直接跑无头模拟、改存档、改代码——门挡不住他，也不需要挡。
- **不要把密钥写进 README、CHANGELOG、文档或启动脚本的默认值。**

## 7. 验收

1. 不设 `NEKO_DEBUG_KEY`，带 `?epoch=7` → **403**，且正文说明门未启用。
2. 设了密钥，带错误密钥 → **403**。
3. 设了密钥，密钥正确 + `?epoch=7` → 200；随后 `/api/snapshot` 里 `era.index` 是 7。
4. `?epoch=99` → **400**，正文带合法范围。
5. 正常玩法（不带参数）行为**一字不变**——这是回归的底线。
6. 调试跳层后确认**没有写存档**（`saves/` 下没有新文件/时间戳未变）。

## 8. 明确不做

- **不动 core**：这是宿主功能，不加公开成员、不升版本、不重生成快照。
- **不做"跳成就/跳升级"**：先只做层。多个调试维度会变成一张越来越长的参数表，
  而层是当前唯一真正卡住人的那个（6 小时）。
- **不做 UI**：只在 URL 上，不给它按钮。调试功能不该出现在玩家界面上。
