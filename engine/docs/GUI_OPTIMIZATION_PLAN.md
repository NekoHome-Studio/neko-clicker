# GUI 优化规划（基于 2026-10-16 实测；P0 与 P1-1/P1-2 已于 **2026-10-19 落地**，见 §6）

> 铁律：**不引框架、不加构建步、不造第二套弹窗、前端不重实现游戏逻辑。**
> 每项落地 = web-smoke 结构守卫 + 判别力证明（弄坏→抄红字→复原→sha256 一致）；
> 像素级/观感断言一律进 H3（本机起不了浏览器，不假装看得见）。
> 状态表三处（OPEN_WORK §1 / STATUS §4 / DEVELOPMENT_SUMMARY §4）随实际数对表。

## 5. 顺序与验收

**P0-1→P0-6 一个代理连续做**（同一机制，样板与守卫共享）→ 量空帧总写入（验收 622→0）→ P1-1/P1-2（小刀）→ P2 按你点头。每步：三套复跑（引擎/烟测/api-test **两种解释器**）+ 判别力证明 + 你的数据不动（size+mtime+sha256）。前端改动刷新即见；**P1-2 是宿主侧 ⇒ 需重建重起**（会提前与你约好时机，重启前先 save）。

## 6. 落地结果（2026-10-19 实测，§1 P0 全部 + §2 P1-1/P1-2）

**总账：空帧 DOM 写入 622 → 0**（同一份真咖啡馆快照：10 建筑 / 49 升级 / 51 图鉴 / 45 成就 / 10 条日志；
同一把量尺——桩件计数器把 `textContent` / `append` / `prepend` / `remove` 全装上、按容器归账）。

| 项 | 基线（写/空帧） | 落地后（写/空帧） | 修法 | 真变化的实测成本 |
|---|---|---|---|---|
| P0-1 `renderCodex` | **272**（含 codex-count 1） | **0** | 结构指纹（storyline 名 + 条目 id 序；**解锁态不进指纹**）+ 行节点按条目 id 复用 + setText | **揭示一条 = 4 写**（计数头 1 + 行类名/标题/正文 3），增量不是重建 |
| P0-2 `renderAchievements` | **227**（含计数头 1） | **0** | 指纹 = 成就 id 序；行内类名 + 两格 setText | 解锁一条 ≤ 4 写，结构不换 |

**守卫**（web-smoke §34 新增 12 条，总数 **271 → 284**）：空帧两连 0 写、每台渲染器一条"真变化照常画"的正面用例（通知 ≤8、图鉴揭示 ≤4 且骨架不换、成就 ≤4、永久线节点不换、金猫到场/同帧/离场、增益跨秒不写）、三处计数头的源码形状守卫（不许再出现 `textContent=` 直写）。
**判别力两针**：① 把图鉴指纹改回"含解锁态 + 总数"（即每帧重建）⇒ 恰红 1 条（`揭示一条图鉴写了 272 次`）；② 把 `number()` 改回旧宽度表 ⇒ 红 6 条（`999999` 期望 `999.999K` 实际 `1000K` 等）。复原后两针的 `app.js` sha256 与破坏前**逐字节相同**（`0872af89…`），284/284 全绿。

**P1-1（D14）落地**：`formatCookies` / `number` 对齐引擎 `Trim(3)`（新 `trimMantissa`：最多 3 位小数、去尾零、`mantissa >= 999.9995` 进位与 `NumFormat.cs:230` 同一条）。
渲染串前后（计数器 / 卡片）：

| 数 | 前（计数器 / 卡片） | 后（计数器 / 卡片） | 引擎 `FormatShort` |
|---|---|---|---|
| `999999` | `1000.0K` / `1000K` | **`999.999K` / `999.999K`** | `999.999K` |
| `123456` | `123.5K` / `123K` | **`123.456K` / `123.456K`** | `123.456K` |

定宽补零（`1.200M` 那一档）原样保留——只在**不改变真值**时使用；宽度取舍会吃掉真值的那一档退回 `Trim(3)` 原文。守卫：§29 扩展 3 条（`999999` 跨套件对读 `NumbersTests` 的 `999.999K`；`123456` 两侧 `123.456K` + 引擎源形状 `Trim(mantissa, 3)`/`999.9995` 在位；`number()` 全表对齐含 `999999.6 → 1M`）。§27 的卡片期望串跟着换过（`7.58K → 7.579K`、`3.40M → 3.4M`、`117M → 117.431M`）。
**P1-2 落地**：`Program.cs` 静态中间件一行 `Cache-Control: no-cache`（`StaticFileOptions.OnPrepareResponse`）；ETag/304 原样。守卫：api-test 新增 2 处（`Cache-Control=no-cache` + `ETag` 在位），**宿主侧 ⇒ 需重建重起才生效**（前端两刀刷新即见）。
