### 2.3 第三批：Linux CI 作业（`6251587` → `ab2834a` → `bcb0a91`）

- **加了 `engine-linux` 作业**（`ubuntu-latest` + **pwsh**，跑**同一条**
  `build.ps1 -Strict -SkipWebSmoke`）——它给"`engine/core` 平台中立"这条主张当**守卫**，
  此前那条主张只由"全仓库只有两处平台相关代码"这句话撑着。
- **它第一次跑就红了，而且红在一个真缺陷上**：Linux 上**两条 sln 都是
  `0 Warning(s) / 0 Error(s)`**，失败的只有一行——
  `The application to execute does not exist: '...\engine\tests\bin\Debug\net8.0\...dll'`。
  根因：**PowerShell 的提供程序**在 Linux 上会把 `\` 归一化（所以 `& "$PSScriptRoot\dnet.ps1"`
  那类调用照样跑得通），但**传给原生进程的参数不会被归一化**——`dotnet exec` 拿到带反斜杠的路径
  直接找不到文件。**形态是最坏的那种：编得过、跑不起来，而 Windows 上永远是绿的。**
- 修法：`build.ps1` 里三处路径一律 `Join-Path` + 正斜杠，判据写进文件顶部注释。
- **副产品（值得留着）**：这个仓库的 **job 日志未登录读不到**（`/actions/jobs/<id>/logs` → **403**），
  而**注解是公开可读的**——所以 Linux 那一步现在失败时用 `::error::` 把日志尾部 30 行打成一条注解。
  上面那段根因就是这么读到的。
- 结果：CI [#41](https://github.com/NekoHome-Studio/neko-clicker/actions/runs/37219888078)
  与随后的文档提交，**四个作业全部 success**。
- **顺带登记 W16**：`pack` / `public-api` / `play` / `start` 里还有 8 处同类路径字面量。

## 3. 怎么自己复跑一遍（判据，不是回忆）

```powershell
# 这一条是全仓库的验收：0 警告 + 571 用例 + 主/Web 两条 sln + 前端冒烟 202
powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\build.ps1 -Strict

# 端到端：真起宿主、真读 SSE、真重启一次读档（65 项，脚本自己核对检查点覆盖）
powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\api-test.ps1

# 打包 + 产物自检（这一步现在有守卫了）
powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\pack.ps1

# "公开 API 一行没动"这条：与上一个 tag 比快照
git diff --numstat v1.10.1 -- engine/core/PublicApi.txt   # 期望 1  1
```

> **本会话的一台机器上的坑**（写下来免得下一个人重新踩）：harness 的 shell 里
> 直接 `.\tools\build.ps1` 会被 PowerShell 拒（`AuthorizationManager check failed`），
> 要用上面那种 `powershell -NoProfile -ExecutionPolicy Bypass -File` 的调法；
> 另：**要看退出码就把输出重定向到文件**（`... *> .tmp\x.log; "EXIT=$LASTEXITCODE"`），
> 别用管道——本轮用管道时出现过一次"输出 571 全绿而进程退出码 1"，重定向重跑是 `EXIT=0`，
> **根因没定位**（记在 `OPEN_WORK` §0.23.10）。`git` 的 "dubious ownership" 用
> `GIT_CONFIG_COUNT=1 / GIT_CONFIG_KEY_0=safe.directory / GIT_CONFIG_VALUE_0="D:/githb/neko-clicker"` 绕过。

- **W9 没在真宿主里一路玩到结局**：验的是"读档那一刻与主线走完那一刻"的表现，
  "结局不再等它"这条判据仍由 in-process 用例守着。
- **W4 的数是这台机器 + 这个运行时的**：换机器要重测，别把 µs 当常量抄走。
- **观感（好不好看）依然没有守卫**：这一轮也没能补——它需要一双眼睛（H3）。
- **一个根因未定位的异常**：管道下 `-Strict` 曾出现"输出全绿而退出码 1"，重定向重跑正常（§3）。
