## 3. 还欠着的（按"该不该先做"排序）

### A. `-Strict` 尚未在合并后跑过一次 ⚠️ 最要紧
我只验到了**文件层面**（改动没被覆盖、端口与锁都干净）。**"合并成功"这句话
我现在没有资格说**——431+ 条用例、两个 sln、0 警告，一次都没在 `6b2199a` 上跑过。
代价：一次 `tools\build.ps1 -Strict`（几分钟）。**在任何别的活之前先做这个。**

### B. `CHANGELOG.md` 第 32 行是一句不真的话
它说"关停时经 `ApplicationStopping` 强制存档一次"。实测**没有发生**：
`StopAsync` 在排入存盘任务**之前**就 `_stopping.Cancel()`，ticker 循环直接退出、任务从未排空。
证据：对照宿主日志说 `Application is shutting down…`，而存档槽没被重写。

**建议**：先**改文档说真话**（"关停不保证存档；请用「存档」按钮"），把 bug 单独记一条。
理由：修它会**改变正常行为**，而"关停该不该存"是产品决定——不该顺手替你定。
（另：调解门下 `StopAsync` 的守卫因此是"防御性"的，它的抑制效果在该 bug 存在时不可观测。）

### C. `Neko`（猫咖物语）没有 `text.json`
11 个包里唯一漏掉的那个，而它正是**框架回归基线**。要么补上，要么在文档里写明
"基线包刻意不外部化"——**但不该既没补也没解释**。

### D. 界面三件
1. **"买得起"只靠颜色**（左侧色条 + 价格颜色）——色觉障碍读不出，普通玩家也易扫漏，该加第二重信号。
2. **`--dim` 对比度未实测**：`#8b86a3` 压在 `#221f30`，用在 `.75rem`（12px）小字上，正处 AA 边界。
   **先算再说**，别凭感觉调。
3. **37 处硬编码颜色 vs 13 个 token**——任何对比度修正都会变成"到处找"。

### E. 宽限期 30 秒仍无人类数据
埋点只在**终端宿主**（`ChoiceLatencyLog`）；**Web 宿主没有**。所以"从外部轮询 HTTP"那条路
（已放弃，沙箱边界）之外，可靠做法是**把埋点做进 Web 宿主、把延迟写进仓库里的文件**——
文件系统是共享的：你跑实例、我读文件。这是清单 #4 唯一缺的一步。

### F. 11 个包里只有 3 个有分支叙事
公司 / 实验室 / 九命有表态+立场+结局；另外 8 个**连 `Choices.cs` 都没有**，结局是"打到终点"
而非"你的选择决定"。**这条被跳过没做，因为它可能是你的设计而不是缺口**——需要你判断。

### G. 难度跨度 1.4h ~ 11.8h
文明 1.4 / 公司 1.9 / 末世 3.0 / 赛博 5.3 / 实验室 5.9 / 梦境 6.0 / 神明 7.5 / 图书馆 11.1 / 九命 11.8
（游戏小时）。8 倍差距是量出来的事实，是否有意为之只有你知道。

### H. 套件墙钟卡在一条用例
并行化后 261s → 149.7s，但**最慢那条 `PrestigeTests` 从 98.5s 被 CPU 竞争拖到 143.9s**，
于是整个套件的墙钟被它一条卡住——**再加线程没有用**。要降只能让那条变便宜
（把 9 个包的"跑一局"在用例之间共享），而它会改变好几个守卫重放的轨迹，需要单独验。

### I. 小清理
`engine/core/NekoClicker.Core.csproj` 里的 `InternalsVisibleTo` 现在多余了（`ContentText` 已 public），
是我当初为"保住绿色仓库"加的过渡措施。
